# MemOS 长期记忆插件

> [my-neuro(肥牛)](https://github.com/morettt/my-neuro) 内置插件发布仓库 · 需要 MemOS 后端服务 · 当前版本：2.2.0

让 AI 拥有跨会话的长期记忆能力，基于 MemOS 后端（Qdrant 向量 + NetworkX 知识图谱 + BM25 混合检索）。**你今天说过的事，明天、下周、甚至重装系统之后，她还记得。**

> **显存不够 / 一边打游戏一边开肥牛？** 记忆检索用的两个模型可以改走硅基流动 **免费 API**，不再占约 6.5GB 显存。注册必须点这个链接：[https://cloud.siliconflow.cn/i/poqaI6Hn](https://cloud.siliconflow.cn/i/poqaI6Hn)。用免费模型 `BAAI/bge-m3` 和 `BAAI/bge-reranker-v2-m3`，**不要选 `Pro/` 开头的收费版**。详细步骤见下面「用免费 API 跑向量和重排序」。

## 这是什么？（给完全没接触过的小白）

- **插件**：给肥牛加功能的"扩展包"，放进插件文件夹、重启一次就生效
- **长期记忆**：普通 AI 聊完就忘（关掉窗口一片空白）。本插件让肥牛把你们的重要对话自动"记进小本本"，以后聊天时自动翻出来用
- **MemOS 后端**：记忆的"仓库管理员"，是另一个独立程序（my-neuro 自带的 `memos_system`），要先把它启动起来，本插件才能存取记忆
- 用起来零操作：正常聊天，她自动记、自动忆；你也可以主动说「记住我喜欢 xx」「我之前跟你说过 xx 吗」

## 环境要求

- my-neuro（live-2d 桌宠）近期版本
- **MemOS 后端服务**（项目自带 `memos_system/`，先启动它本插件才有记忆可存取）
- 后端 LLM：一把用于记忆总结/实体提取的 API Key（在插件配置页填写）
- **若要用免费向量 API**：后端需要已经支持 `embedding.provider=api`（只更新本插件、后端仍是旧版时，设置会写入配置文件，旧后端仍走本地模型）

## 快速开始

1. 启动 MemOS 后端：运行 `memos_system/start_memos.bat`（首次若走本地模型，需等待 Embedding 加载）
2. 在插件配置页面确认 **启用 MemOS** 为开启状态
3. 确认 **MemOS API 地址** 为 `http://127.0.0.1:8003`
4. 开始对话即可，插件会自动检索和保存记忆
5. 显存不够时，按下一节改成免费 API，再重启记忆系统

## 用免费 API 跑向量和重排序（推荐显存不够时）

记忆检索有两个模型：一个把文字变成向量（`BAAI/bge-m3`），一个给结果重新打分（`BAAI/bge-reranker-v2-m3`）。本地跑大约要占 6.5GB 显存；改成硅基流动 API 后，用的是**同一套模型、同一个 1024 维空间**，旧记忆不用重建，只是计算改去云端。

这两条在硅基流动价格页上是 **免费模型**（有固定速率限制，不是无限并发）。注册、创建 Key 都免费。新用户另外可能有约 ¥16 赠金（以注册页当时展示为准），日常记忆检索用下面两个免费模型即可，一般不用花赠金。

### 第 1 步：用邀请链接注册（不要直接打开官网首页）

1. 打开邀请链接：**[https://cloud.siliconflow.cn/i/poqaI6Hn](https://cloud.siliconflow.cn/i/poqaI6Hn)**
2. 用手机号完成注册。必须走这个链接，邀请和当时的新用户福利才能记上
3. 建议按控制台提示完成实名，才能用齐免费模型

### 第 2 步：确认模型是免费的那两个，不要选 Pro

| 用途 | 必须填的模型名 | 说明 |
|------|----------------|------|
| 向量 | `BAAI/bge-m3` | 免费。不要改成别的向量模型，否则旧记忆搜不到 |
| 重排序 | `BAAI/bge-reranker-v2-m3` | 免费 |

不要选 `Pro/BAAI/bge-m3` 或 `Pro/BAAI/bge-reranker-v2-m3`，那是收费版。

### 第 3 步：创建 API Key

1. 登录硅基流动控制台，打开 API 密钥页
2. 新建一把 Key。它一般以 `sk-` 开头
3. Key 只给自己看，不要发给别人，也不要提交到 GitHub

### 第 4 步：在肥牛插件里填写

1. 打开 WebUI → 插件 → MemOS → 配置
2. 找到「后端向量模型与重排序器」
3. 运行方式选 **API 调用**（若界面是文本框，填 `api`）
4. API 地址保持 `https://api.siliconflow.cn/v1`（**不要改成 `.com` 国际节点**）
5. 把你自己的 Key 贴进去
6. 两个模型名保持默认，一般不用改
7. 点保存

桌宠要开着，插件才会把设置写进 `memos_system/config/memos_config.json`。

### 第 5 步：重启记忆系统（只保存不够）

- 有「服务面板」的：记忆系统点「停止」，再点「启动」
- 只有 BAT 的：关掉正在跑的 `start_memos.bat` 窗口，再运行一次

### 第 6 步：怎么确认成功

1. 浏览器打开 `http://127.0.0.1:8003/health`
2. 看到 `embedding.provider` 为 `api`，`embedding.ready` 为 true，`warning` 为空
3. 显卡计算进程里不应再出现 memos 的本地 embedding
4. 说一句以前聊过的事，她还能想起来（模型没换，不用重建库）

### 失败时怎么处理

- 选了 API 但 Key 是空的：后端会按本地模型启动并提示，记忆还能用，但显存还在
- `/health` 或日志里出现 401：Key 错了，或复制少了字符
- 搜不到旧记忆：模型名被改过，改回 `BAAI/bge-m3` 并重启
- 第一句没记忆：API 比本地慢约 1～3 秒，本版本检索超时已改到 6 秒

### 隐私说明

选 API 后，检索问句、写入的记忆文本、知识库文档内容会发送到硅基流动。不想出网就改回「本地模型」并重启记忆系统。

## 配置说明

### 前端配置（插件行为）

| 配置项 | 说明 |
|--------|------|
| 启用 MemOS | 总开关，关闭后所有记忆功能停用 |
| MemOS API 地址 | 后端服务地址，默认 `http://127.0.0.1:8003` |
| 自动注入记忆 | 用户说话时自动检索相关记忆注入到系统提示词 |
| 注入记忆条数 | 每次注入的最大记忆条数，默认 3 |
| 相似度阈值 | 低于此值的记忆不注入，默认 0.6 |
| 自动保存对话 | LLM 回复后自动累积保存对话到长期记忆 |
| 保存间隔 | 每隔多少轮对话批量保存一次，默认 5 轮 |
| 提取失败提醒阈值 | 后端记忆提取连续失败达到此次数时在屏幕上提醒一次，默认 3 次 |
| 提取失败时保留对话重试 | 提取失败时把对话留在缓冲里，退避后随下一批重试，默认开启 |
| 重试缓冲上限 | 持续失败时最多保留的对话轮数，默认 15 轮 |

### 后端配置（MemOS 服务）

以下配置会在插件启动或保存设置时自动同步到 `memos_system/config/memos_config.json`，无需手动编辑后端配置文件。

| 配置项 | 说明 |
|--------|------|
| 后端 LLM 模型 / API Key / Base URL | MemOS 后端用于总结对话、提取实体的 LLM |
| 后端备用 LLM | 主 LLM 失败时的自动切换备用模型 |
| 启用 BM25 混合检索 | 开启向量 + 关键词双路检索，提升召回率 |
| BM25 权重 | BM25 在混合检索中的占比，默认 0.3 |
| 启用知识图谱增强 | 利用实体关系图谱扩展检索结果 |
| 后端向量模型与重排序器 | 本地模型或硅基流动免费 API。默认本地。免费注册走上方邀请链接。保存后必须重启记忆系统 |
| 自动实体提取 | 添加记忆时提取人名、地点等实体到知识图谱 |
| 图片记忆 | 启用图片上传、截图保存等功能 |
| 图片自动描述 | 上传图片时自动用 LLM 生成描述文本 |

## 主要功能

### 自动记忆注入

用户每次说话时，插件自动从后端检索相关记忆并注入到系统提示词。AI 无需调用工具就能"回忆起"历史信息。短句（「嗯」「好的」等）会跳过检索，少打无意义请求。

### 自动对话保存

LLM 回复后，插件自动将对话累积到缓存，每 N 轮批量发送到后端，由后端 LLM 总结提取后存入向量库。程序退出时会自动保存未达到间隔的缓存。提取失败时默认保留对话并退避重试，避免对话白白丢掉。

### Function Call 工具

插件提供 12 个工具，AI 可主动调用：

| 工具 | 功能 |
|------|------|
| `memos_search_memory` | 深度搜索历史记忆 |
| `memos_add_memory` | 手动添加重要信息 |
| `memos_upload_image` | 上传图片到记忆 |
| `memos_search_images` | 搜索图片记忆 |
| `memos_save_screenshot` | 截屏并保存到记忆 |
| `memos_save_image_from_file` | 从本地文件保存图片 |
| `memos_record_tool_usage` | 记录工具使用情况 |
| `memos_search_tool_usage` | 搜索工具使用记录 |
| `memos_import_url` | 导入网页内容到记忆 |
| `memos_import_document` | 导入文档（txt/pdf/md） |
| `memos_correct_memory` | 修正/补充/删除记忆 |
| `memos_get_preferences` | 查询用户偏好摘要 |

## 使用教程（照着说就行）

启动后端、启用插件后：

- 「记住：我对芒果过敏」→ 她会存进长期记忆，以后推荐食物时会避开
- 「你还记得我上次说想买什么吗？」→ 她自动检索历史记忆回答
- 「把你刚说的整理成一条记忆」→ 用 `memos_add_memory` 显式保存
- 「帮我看看上上周我们聊过哪些电影」→ 深度搜索历史对话

## 后端服务

MemOS 后端是一个独立的 Python FastAPI 服务，提供 60+ 个 API 端点。

### 启动方式

```bash
# Windows
memos_system\start_memos.bat

# 或 PowerShell
memos_system\start_memos.ps1
```

### 技术栈

- **向量存储**：Qdrant（本地嵌入式）
- **知识图谱**：NetworkX（轻量图存储）
- **混合检索**：向量相似度 + BM25 关键词 + 图谱增强
- **Embedding / 重排序**：本地 SentenceTransformer，或同一模型的硅基流动免费 API（`BAAI/bge-m3` + `BAAI/bge-reranker-v2-m3`）
- **记忆处理**：LLM 自动总结、去重、合并、分类

### Web 管理界面

```bash
memos_system\启动WebUI_v3.bat
```

可在浏览器中管理所有记忆、查看知识图谱、测试检索效果。

## 常见问题（FAQ）

**Q: 启动后提示 "MemOS 服务不可用"？**
A: 确保先运行了 `start_memos.bat`。本地模型要等 "Embedding 模型已加载"；API 模式则看 `/health` 里 `embedding.provider=api`。

**Q: 记忆为什么没有立即保存？**
A: 插件使用批量保存策略，默认每 5 轮对话保存一次。可在配置中调整保存间隔，或程序退出时会自动保存。

**Q: 修改了后端配置为什么没生效？**
A: 插件配置页的后端设置会在桌宠运行时很快同步到 `memos_config.json`；桌宠没开则下次启动时同步。向量模式（本地 / API）改完后，还要把记忆系统停止再启动才生效。

**Q: 改了向量模式为什么还在占显存？**
A: 只改插件设置不够，必须重启记忆系统。若选了 API 却没填 Key，后端会按本地模型启动并提示。另外：只更新本插件、后端还是旧版时，旧后端仍会加载本地模型。

**Q: 必须走邀请链接注册吗？**
A: 要。请打开 [https://cloud.siliconflow.cn/i/poqaI6Hn](https://cloud.siliconflow.cn/i/poqaI6Hn)，不要直接打开官网首页，否则邀请和新用户福利可能记不上。

**Q: Pro 版和免费版有什么差别？**
A: 免费用 `BAAI/bge-m3` 和 `BAAI/bge-reranker-v2-m3`。名字前面加了 `Pro/` 就是收费版，本教程不需要。

**Q: 它记的东西会占我的对话上下文吗？**
A: 只注入与当前话题相关的少数几条（默认 3 条，可调），不是把整个记忆库塞进去。

**Q: 想删掉某条她记错的信息？**
A: 对她说「忘掉/更正 xx」走 `memos_correct_memory`，或在 MemOS WebUI 里手动管理。

**Q: 重装系统/换电脑记忆会丢吗？**
A: 记忆存在后端数据目录里，备份 `memos_system` 的数据目录即可迁移。

**Q: 屏幕上出现"MemOS 记忆提取已连续失败 N 次"是什么意思？**
A: 后端能收到对话，但用于提取记忆的大模型连续失败了。对话默认会留在缓冲里重试；请检查插件里的「后端 LLM 配置」。

## 故障排查

1. 主程序日志搜 `memos`，可看到检索、保存的每次调用与报错
2. 检索结果总是空：确认后端已启动、`MemOS API 地址` 端口一致、库里确实存过记忆、向量模型名仍是 `BAAI/bge-m3`
3. API 模式看 `http://127.0.0.1:8003/health` 的 `embedding` 字段
4. 还有问题请到 [本仓库 Issues](https://github.com/A-night-owl-Rabbit/my-neuro-plugin-memos/issues) 提问
